# Exemplos de perguntas e respostas

Este arquivo guarda uma sessão **real** do chatbot. Os testes automatizados usam um modelo
falso, então as respostas abaixo só existem depois que você roda o programa com a sua chave
da OpenAI. Nada aqui foi escrito à mão ou inventado.

## Como gerar

```bash
python -m chatbot
```

Faça as perguntas abaixo, na ordem, e cole a saída do terminal na seção seguinte.

| # | Pergunta | O que demonstra |
|---|----------|-----------------|
| 1 | `Como criar uma lista em Python?` | Resposta detalhada, com exemplo de código |
| 2 | `E como adiciono um item no final dela?` | Memória da conversa ("dela" só faz sentido pelo contexto) |
| 3 | `Qual a diferença entre lista e tupla?` | Explicação comparativa |
| 4 | `Qual a capital da França?` | Pergunta fora do escopo: o tutor deve recusar educadamente |
